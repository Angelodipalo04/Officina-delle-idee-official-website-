# Locandine eventi

Metti qui i file PDF (o immagine) delle locandine, uno per evento.

Il nome del file deve corrispondere esattamente al percorso indicato
nell'attributo `data-locandina` della scheda evento in `eventi.html`.

Finché un file non è presente, il link "Scarica la locandina" nella modale
punta comunque al percorso previsto: basta caricare qui il file con lo
stesso nome per attivarlo, senza toccare il codice.
